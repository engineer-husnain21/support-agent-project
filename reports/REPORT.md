## 4. What the resolution percentage counts

**Auto-resolved correctly** = tickets that should be auto-resolved AND were handled exactly as expected (right outcome and right data changes), divided by all 40 tickets. A ticket that was escalated, or where the agent only asked a question, is NOT counted as resolved, even if it was handled safely. A reply is never counted as resolved when the data does not match what the reply says.

## 7. Limitations

- The mock tickets come from templates and the screen rules were written while looking at them, so real tickets would be messier.
- 40 tickets is a small set: one ticket moves a percentage by 2.5 points.
- Reply checks are keyword checks. Tone and writing quality are not scored.
- Refunds and emails are simulated.
- Runs may use different LLM providers (free daily limits); see section 1.
- The agent was improved after run 1, using the two wrong replies of that run, which belong to this same test set (METRICS.md, section 9). The final numbers are therefore optimistic: they are not a measurement on tickets the agent has never seen.
- The model runs with temperature 0, so the runs are nearly identical. The spread shows how stable the setup is; it is not three independent exams.
